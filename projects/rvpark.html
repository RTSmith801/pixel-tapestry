# RV Park Management System ## Developing a Full-Stack Reservation & Management Application **Project Type:** Software Engineering II **Organization:** Weber State University **Team Size:** 6 Developers **Development Period:** Spring 2026 **My Role:** Full-Stack Software Developer ### Project Overview The RV Park Management System is a full-stack web application developed as part of Weber State University's Software Engineering II course. The project was designed to provide a centralized management platform for RV park operations, bringing together customer information, vehicle registrations, reservations, campsite availability, and administrative functionality. Working as part of a six-person development team, we developed the application around client requirements and user stories, translating those requirements into functional application features. Unlike a standalone programming assignment, this project involved coordinating development across multiple application layers, working with a shared codebase, and implementing features that needed to integrate with the broader application. ### The Problem Managing an RV park involves coordinating several interconnected operations. Customer accounts, vehicle information, reservation records, campsite assignments, and payment information all need to work together. The application was designed to bring these operations into one system, allowing users and administrators to interact with the information through a centralized web interface. ### My Role & Contributions As part of a six-person development team, I contributed to the application's frontend, backend, and database implementation. My work was driven by client stories and requirements, and included developing features across multiple areas of the application. **1. User Registration & Authentication** Contributed to the user account and authentication functionality. - Developed registration-related functionality. - Worked on authentication and user account workflows. - Implemented functionality for managing user profiles. - Worked with application data retrieval and database queries. **2. Reservation Management** Contributed to the reservation functionality that forms the core of the application. - Developed reservation-related application functionality. - Worked with SQL queries to retrieve reservation information associated with individual users. - Implemented functionality connecting user accounts with their reservation records. - Worked with the underlying database structure supporting reservations and related records. **3. Database Integration** Worked with the SQL database layer to connect application functionality with persistent data. - Implemented database queries using C# and ADO.NET. - Worked with parameterized SQL queries to retrieve user reservation information. - Integrated database operations into the application's backend. - Worked with interconnected records involving users, clients, vehicles, reservations, and campsite assignments. **4. Application Services & User Experience** Contributed to additional application functionality and interface improvements. - Worked on the email service using SMTP. - Contributed to pricing-related functionality. - Improved application feedback and user interface behavior. - Implemented features based on client requirements and project user stories. ### Technical Implementation **Frontend & Application Framework** The application was developed using ASP.NET Core and Razor Pages, with C# providing the primary application logic. Razor Pages provided a structured approach to building server-rendered pages and integrating application functionality with the backend. **Backend & Database Access** C# and ADO.NET were used to implement application logic and communicate with Microsoft SQL Server. SQL queries handled data retrieval and operations involving user accounts, reservations, vehicles, and other application records. **Authentication & Application Services** The application included cookie-based authentication and an SMTP email service for application communications. **Cloud Infrastructure** The original application was configured around Azure services, including Azure App Service and Azure SQL. ### Challenges & Problem Solving **Working Across Multiple Application Layers** One of the most valuable aspects of this project was developing features that required coordination between Razor Pages, backend application logic, and SQL database operations. A user-facing feature often required more than simply creating a page. It also required retrieving the appropriate data, processing it through the backend, and ensuring that the database operations supported the intended workflow. **Working With Complex Database Relationships** Reservation management involves multiple interconnected records. For example, retrieving a user's reservations requires connecting the user account to the appropriate reservation records through the database. Working with these relationships helped develop a stronger understanding of SQL queries, database structure, and the importance of retrieving the correct records efficiently. **Developing From Client Requirements** The project required translating client stories into functional application features. This meant understanding what the application needed to accomplish, identifying the necessary implementation work, and coordinating changes within a shared codebase. ### What I Learned The RV Park project provided valuable experience working on a larger team-based software engineering project. It strengthened my understanding of: - Full-stack development using ASP.NET Core and C#. - Server-rendered application development with Razor Pages. - SQL database integration and ADO.NET. - Parameterized SQL queries and database relationships. - Authentication and user account workflows. - Implementing features from client stories and requirements. - Coordinating frontend, backend, and database development within a team.
